Links externos:

Links que sobrepõem meu site Clique aqui krl , usamos a tag "a". Note que terá 2 espaços para botar o link:

  1. entre os ""
  2. e outro para escrever a frase que estara atrelada ao link no site

Links que abrem o conteudo em outro aba Clique como um bom garoto, mesma tag "a", e perceba que agora tem 2 espaços

  • O espaço de colocar "target blanck" que é o que vai fazer mandar o usuario pra outra aba
  • E o outro espaço para garantir maior segurança "rel = external"

Link interno:

Links de arquivos do computador Clique Aqui, e como o de cima, poemos colocar target "_black" para abrir em outra aba o link
E podemos colocar o rel "external/prev/next/unfoloow(propaganda)" dependendo do contexto para garantir semantica e segurança.

Adendo, existe o target"self" para sobrepor o site, podemos colocar só para ficar mais formal o codigo.
