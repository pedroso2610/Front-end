Imagem Dinamica

Vamos colocar uma imagem dinamica aqui, diminua a tela do navegador para ver, é feito entre a tag picture , para indicar que alguma imagem será colocada, depois usaremos a tag img para se referir a maior imagem que vamos admitir até o infinito, e botaremos varias tags source que vão servir como uma especie de condição para novas imagens menores entrarem(Na verdade a tag source sempre será no sentido de condição para importar videos, fotos, audios), na parte da media vamos definir o max de largura que a imagem vai assumir , e no srcet botamos o caminho da imagem, lembrando que a imagem maior não terá a source pois ela não tem limite . A logica é, o site sempre vai tentar abrir a primeira imagem que der de cima para baixo no codigo, por isso a condição é importante e a ordem.
